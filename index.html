OpenMUN — Plataforma Educativa Libre para Modelos de Naciones Unidas

OpenMUN es una aplicación web educativa desarrollada para estudiantes, profesores y colegios que participan en simulaciones diplomáticas y Modelos de Naciones Unidas (MUN). Permite a las Mesas de Presidencia moderar debates, cronometrar caucuses, gestionar listas de oradores y realizar votaciones parlamentarias en tiempo real sin coste alguno.

Propósito de la Aplicación y Caso de Uso

Los Modelos de Naciones Unidas (MUN) son simulaciones académicas donde los alumnos representan delegaciones diplomáticas de países de la ONU para debatir retos globales. OpenMUN proporciona las herramientas digitales necesarias para moderar estas simulaciones de forma ágil, eliminando la necesidad de servidores complejos o papel físico.

Integración con Google Drive y Uso de Datos de Google

OpenMUN incluye una funcionalidad opcional de sincronización y respaldo con Google Drive. La finalidad exclusiva de esta integración es permitir a los usuarios guardar y recuperar copias de seguridad de sus comités (archivos en formato JSON con listas de países y configuraciones de debate) en su propio almacenamiento en la nube de Google Drive.

  • Seguridad del lado del cliente: La app funciona íntegramente en el navegador web (client-side). Los tokens y archivos nunca se almacenan en servidores de OpenMUN.
  • Privacidad garantizada: No vendemos datos de usuarios ni los compartimos con terceros. Los datos de Google nunca se utilizan para publicidad ni para entrenar modelos de Inteligencia Artificial.
  • Cumplimiento estricto: El uso de la información recibida de las API de Google se ajusta a la Política de datos del usuario de los servicios de las API de Google, incluidos los requisitos de Uso Limitado (Limited Use).

Características Principales para Comités MUN

  • Lista General de Oradores (GSL): Gestión fluida de delegaciones con tiempos configurables por orador, cesiones de palabra y cola en tiempo real.
  • Cronómetros Dinámicos: Control preciso de debates moderados e inmoderados con alertas visuales y sonoras.
  • Gestión de Quórum y Asistencia: Matriz de países con cálculo automático de mayorías simples, 2/3 y cualificadas.
  • Pizarra de Mociones y Votación Oficial: Registro jerárquico de mociones, votaciones procedimentales/sustantivas y mapa de votos.
  • Sincronización en Tiempo Real: Comunicación WebSocket cifrada para conectar proyectores, secretarías y delegaciones.
  • 100% Software Libre y Gratuito: Licencia libre GNU AGPLv3 para su uso en cualquier escuela o universidad.
